# 2차시 — 엣지 케이스 #1: 0으로 나누기

> 목표: **실패하는 테스트로 버그를 재현(red) → 고쳐서 초록(green) → PR로 기록.** 이것이 이 강의의 반복 리듬입니다.

## ❓ Q. 할인 계산에서 수량이 0이면 무슨 일이 일어나지?
**A.** `DiscountService.CalculateUnitPrice` 는 `총액 / 수량` 을 그대로 계산합니다.
`decimal` 에서 0으로 나누면 **`DivideByZeroException`** 이 터집니다. 사용자가 수량을 비우면 앱이 죽습니다.

## 1단계 — 버그 재현 (red)
`tests/DiscountCalculator.Tests/DiscountServiceTests.cs` 아래쪽 주석 처리된 테스트의 주석을 해제합니다.

```csharp
[Fact]
public void CalculateUnitPrice_수량이_0이면_단가는_0이다()
{
    var service = new DiscountService();

    var unitPrice = service.CalculateUnitPrice(1000m, 0);

    Assert.Equal(0m, unitPrice);
}
```

```bash
git switch -c fix/unit-price-divide-by-zero
dotnet test          # ← 빨강! DivideByZeroException 확인
git add tests/
git commit -m "test: 수량 0일 때 단가 계산 실패 케이스 추가"
```

> 💡 **왜 테스트를 먼저 커밋하나?** PR을 보는 사람이 "무엇이 깨져 있었는지"를 커밋 히스토리로 바로 이해할 수 있기 때문입니다.

## 2단계 — 수정 (green)
`src/DiscountCalculator/DiscountService.cs` 의 `CalculateUnitPrice` 를 고칩니다.

```csharp
public decimal CalculateUnitPrice(decimal totalAmount, int quantity)
{
    if (quantity == 0)
    {
        return 0m;   // 수량이 없으면 단가도 0으로 정의
    }

    return totalAmount / quantity;
}
```

```bash
dotnet test          # ← 초록! 3개 통과
git add src/
git commit -m "fix: 수량 0일 때 DivideByZeroException 방지"
git push -u origin fix/unit-price-divide-by-zero
```

## 3단계 — PR 작성
GitHub에서 PR을 열고 아래 템플릿으로 본문을 채웁니다.

```markdown
## 무엇을 (What)
수량이 0일 때 CalculateUnitPrice 가 DivideByZeroException 을 던지는 버그 수정

## 왜 / 문제 상황 (Why)
재현: CalculateUnitPrice(1000, 0) → DivideByZeroException
원인: 총액 / 수량 에서 0 나눗셈을 검증하지 않음

## 어떻게 (How)
수량이 0이면 단가 0으로 정의하고 early return

## 테스트
- 추가한 실패 테스트 "수량이_0이면_단가는_0이다" 통과 확인
- 기존 테스트 2개 모두 통과
```

## ❓ Q. 리뷰 코멘트가 달렸다. 새 PR을 여나, 기존 PR에 커밋을 더하나?
**A.** **기존 PR에 커밋을 더합니다.** 같은 브랜치에 commit + push 하면 PR이 자동 갱신됩니다. PR은 "하나의 작업 단위" 동안 계속 살아있는 대화창입니다.
